AWS Certified Solutions Architect: Practice Questions

Hands-on questions, exam strategy, FAQs, and resources.

7-Day Study Plan

  1. Core services: IAM, VPC, EC2, S3, CloudFront
  2. Databases: RDS/Aurora/DynamoDB, backups, DR basics
  3. Compute patterns: Lambda, ECS/EKS, Auto Scaling
  4. Networking: endpoints, VPN/Direct Connect, routing
  5. Security: KMS, policies, logging, least privilege
  6. Resilience: Multi-AZ vs Multi-Region, RTO/RPO
  7. Mixed practice set + review weak domains

Practice Questions (sample)

Q1. Best way to serve a static website globally with lowest latency and minimal ops?

A. S3 + CloudFront + Route 53. Use origin access control and cache-control headers.

Q2. Need automatic scaling for spiky background jobs and minimal management?

A. SQS + Lambda event source mapping. Set concurrency and batch size.

Q3. Shared filesystem across multiple EC2 instances across AZs?

A. EFS with mount targets in multiple AZs.

FAQs

How should I review wrong answers? Write why each wrong option violates requirements (latency, availability, cost, security).

How many questions per day? Start with 15–25 mixed questions/day, then increase once accuracy stabilizes.
