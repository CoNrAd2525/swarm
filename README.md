## 🛠 Setup

1. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Configure `.env`**:
   - Get `TELEGRAM_API_ID` and `TELEGRAM_API_HASH` from https://my.telegram.org.

3. **Run**:
   ```bash
   python src/main.py
   ```

4. **Open Dashboard**:
   - Go to `http://localhost:5000` on your PC or Mobile.
