Cybersecurity CEH: Hands-on Labs

Recon, exploitation basics, and defensive validation in a safe lab environment.

Step-by-step Lab Path

  1. Set up a safe lab (VMs + isolated network)
  2. Recon: DNS, ports, service fingerprinting
  3. Web testing: auth, input validation, sessions
  4. Exploit fundamentals in labs only (no real targets)
  5. Privilege escalation patterns (Linux/Windows)
  6. Logging + detection: validate what defenders see
  7. Report writing: findings, impact, remediation

Practice Tasks

  • Scan a lab target, list services, map each service to an attack surface.
  • Write mitigations for each finding (patch, config, WAF, segmentation).
  • Re-test after remediation and document verification steps.

FAQs

Do I need paid tools? No. Start with free lab tooling and focus on methodology and reporting.

How do I stay compliant? Use only owned/lab targets; keep written authorization for any testing outside your lab.
